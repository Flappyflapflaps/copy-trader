# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/drive/12WWQAaAwXzVpblCpZ4DbhUvI4Hj7GUjn

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Copy the `.env.example` file to a new file named `.env`.
3. Open the `.env` file and set the `VITE_HELIUS_API_KEY` to your Helius API key. You can get a free key from [Helius](https://helius.dev/).
4. Run the app:
   `npm run dev`

### For Windows Users

For convenience, you can use the provided batch files to manage the application:
- **To start the bot:** Double-click on `start.bat`.
- **To stop the bot:** Double-click on `stop.bat`.
